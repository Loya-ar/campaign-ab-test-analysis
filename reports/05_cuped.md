# Step 5: CUPED

Generated by `python scripts/cuped_analysis.py`.

CUPED replaces each outcome y with y − θ(x − x̄), where x is pre-period `history` (dollars spent in the past year) and θ = cov(y, x) / var(x) is estimated on treatment and control pooled. The point estimate stays unbiased because x was fixed before randomisation; the variance falls by about ρ², where ρ is the correlation between y and x.

As a comparison, the last columns use **regression adjustment** with all 11 pre-period features (OLS of y on treatment + centred covariates, HC1 robust standard errors). This is CUPED generalised to several covariates.

## Reading the table

- Largest CUPED variance reduction: **0.44%** (Visit, Men's email), equivalent to running the test with 0.4% fewer customers for the same precision.
- Variance reduction ≈ ρ², so a covariate only helps as much as it correlates with the outcome. Past-year spend correlates only weakly with buying in a 2-week window, because purchases are rare.
